# JavaScriptSolidServer mind maps

Every repo in the org and its open issues as [Mindstr](https://mindstr.org) maps,
generated from the repos' READMEs and GitHub issues.

**Open the org map:** https://mindstr.org/?uri=https://javascriptsolidserver.github.io/mindstr/index.jsonld

| File | What it is |
| --- | --- |
| `index.jsonld` | The org map: repos by group, each linking to its own map |
| `repo-<name>.jsonld` | One repo: README sections, last commit, open issue count |
| `issues-<name>*.jsonld` | A repo's open issues by label and by month |
| `outline.md` | The whole set as one nested Markdown outline, for people and LLMs |

Convention: an org has a `mindstr` repo, a repo has a `mindstr/` folder. The JSS docs,
CLI, source and plugins are at https://jss.live/docs/mindstr/ (see the
[Mind Maps guide](https://jss.live/docs/guides/mind-maps)).
